我发现很多人其实就是本地小模型，特点如下：

参数量：约 2B，甚至更小
训练集：极小，而且混有大量污染数据
预训练：轮数不足，通常没有完全收敛
上下文窗口：不超过 500 字，三句话以前的前提随时丢失
注意力机制：稀疏注意力，只关注自己想看的 token
长上下文召回：接近 0
联网搜索：不支持
RAG：无
知识更新：靠短视频、群聊和朋友圈手动注入
推理能力：有限
思维链：无
指令遵循：选择性遵循
拒绝采样：“反正我不信”
幻觉率：极高
置信度校准：不存在，通常越不知道越自信
Self-correction：发现错误后重新生成一遍原答案
Temperature：发生争论后自动升至 2.0
上下文压缩：自动把对方 2000 字压缩成一句最容易反驳的话
微调方式：亲友、学校和互联网长期 LoRA
系统提示词：童年环境与固有观念，权重极高且难以覆盖
Reward Model：谁让我舒服谁得高分
对齐方式：“大家都这么觉得”
Benchmark：只跑自己出的测试集
模型更新：新证据与 system prompt 冲突时拒绝安装
灾难性遗忘：严重
量化精度：复杂观点经过几轮转述后自动 INT2
最终输出：不是幻觉就是过拟合
可解释性：“这不是很明显吗？”

最神奇的是，这种模型通常还不允许你查看模型卡，训练数据不公开，评测集不公开，已知缺陷不公开，适用范围不公开，但每次生成答案的时候置信度都是 99.9%
